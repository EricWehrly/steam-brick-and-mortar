# desktop/

Home for offline/local tooling that runs outside the browser — currently the Source 1 asset
extraction pipeline, and eventually the native desktop app (see `docs/features/desktop-app.md`).

```
desktop/
└── source-extract/     # Source 1 game files → glTF/GLB, see its own README
```

See **`source-extract/scripts/README.md`** for the full pipeline: prerequisites, quick start,
adding a new game, and troubleshooting.
